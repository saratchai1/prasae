# Prasae Mangrove Monitoring

Live: https://saratchai1.github.io/prasae/

## Viewer contract

- exactly 12 declared Sentinel-2 observation/composite months
- no nearest-month substitution, interpolation, or synthetic imagery/statistics
- Esri World Imagery remains the permanent basemap
- Sentinel imagery is clipped to the exact plot Polygon/MultiPolygon, including holes
- stable frame swapping keeps the previous Sentinel frame visible until the replacement is ready
- Before/After uses a single-map swipe divider over Esri World Imagery
- Sentinel/NDVI opacity can be adjusted without changing the Esri basemap
- selecting another plot refreshes detail, compare, metrics, and Spectral Studio state

Dates: 2023-09, 2023-12, 2024-03, 2024-06, 2024-09, 2024-12, 2025-03, 2025-06, 2025-09, 2025-12, 2026-03, 2026-08.

## Verified metrics

Verified statistics are generated by the `process_verified_12_dates_v4.py` pipeline and stored in `data/timeseries_verified_12.json`.

The dashboard separates:

- whole-plot NDVI
- Green Cover Proxy with calibration provenance
- vegetation-only NDVI
- NDRE
- Open Water / MNDWI context
- MFI-in-water diagnostic
- observation QA and comparability

See `METRICS.md` for definitions and limitations.

## Spectral Studio

`Spectral Studio` is a browser-side visualization mixer. It uses six lightweight, cloud-masked, polygon-clipped Sentinel-2 visualization bands:

- B02 Blue
- B03 Green
- B04 Red
- B08 NIR
- B11 SWIR1
- B12 SWIR2

Preset views:

- True Color: B04 / B03 / B02
- Color Infrared (CIR): B08 / B04 / B03
- SWIR Agriculture: B11 / B08 / B02
- NDWI Water Index: `(B03 - B08) / (B03 + B08)`

The browser also provides custom R/G/B selection plus Brightness, Contrast, Gamma, and Opacity controls.

Band PNGs are generated by:

```bash
PRASAE_PLOT_IDS=76 python build_spectral_assets.py
```

They are fixed-scale 8-bit visualization assets only. Scientific metrics continue to use the original floating-point reflectance pipeline.

The automated PLOT_076 asset build is defined in `.github/workflows/build-spectral-assets.yml`.
